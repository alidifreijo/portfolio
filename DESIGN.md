# Design system · the rules

The portfolio's design system, in plain words, for anyone (person or agent) who builds a page. It is style v3, approved by Ali on 27 Nov 2026 (`estilos/`). If something here and `estilos/` disagree, `estilos/` wins and this file is wrong.

## Where things live

| What | File | Who writes it |
| --- | --- | --- |
| The approved style, in Spanish | `estilos/LEEME.md`, `estilos/tokens.css` | Ali (changing a token is a question of taste: it needs her yes) |
| Tokens as CSS variables | `src/styles/tokens.css` | Generated by `npm run tokens`. Never edit by hand |
| Tokens as data (DTCG format) | `src/styles/tokens.json` | Generated by `npm run tokens` |
| The base components | `src/components/system/*.astro` | Builders, following this file |
| What each component is for | `src/components/system/manifest.json` | Builders, with every component |
| The living guide | `/styleguide` | Generated from the two files above |
| Old pages' debt | `src/styles/system-debt.json` | The check. It only goes down |

## The check

`npm run build` runs `npm run check` first. The build fails if:

- the token copies are out of date with `estilos/tokens.css`;
- any page or component uses a colour, font size, font family, radius, spacing or shadow that isn't a token;
- anything uses a blur or a gradient;
- anything uses DM Sans, DM Mono or Caveat (they left the system);
- anything uses a v2 legacy token (`src/styles/legacy-tokens.css`) more than it already did;
- a system component isn't in the manifest, or the manifest lists one that doesn't exist.

Old pages are being rebuilt in blocks 2–4. Until then their breaks are recorded in `system-debt.json`: a file may never go above its count, and a new file must have none. After rebuilding a page, run `npm run check:system -- --shrink` to lower its count. The count can't go up: there is no command for that, on purpose.

## The frame

- Every page: black frame (`--ink`) with the header on it, and inside, a paper panel (`--paper`) with a 12 px radius (`--r-md`).
- The header has the á (home), the menu (Play, Work, About, Contact), "Based in" with the time, "Up for: Meeting people and good collabs" and the email.
- The same footer on every page: LinkedIn, CV and "Let's talk".

## Type: three families, five sizes

| Family | Token | It is | Use it for |
| --- | --- | --- | --- |
| Instrument Serif | `--font-serif` | the voice | headlines, sections, chapters, loose notes (in italics). The important part of a headline goes in italics |
| Space Grotesk | `--font-ui` | the interface | menu, labels, buttons, names, agent cards |
| Satoshi | `--font-body` | the text | everything you read |

| Size | Token | For |
| --- | --- | --- |
| Display | `--fs-display` | the home headline |
| Section | `--fs-section` | section titles ("In short", "Work"), case names |
| Chapter | `--fs-chapter` | chapter titles |
| Text | `--fs-text` | text and values |
| Label | `--fs-label` | labels, always in capitals |

Nothing outside this scale. Each size has its line height (`--lh-*`). Shortcuts: the classes `.type-display`, `.type-section`, `.type-chapter`, `.type-text`, `.type-label`.

## Colour

- Base: `--ink`, `--paper`, `--paper-2`, `--paper-3`, `--muted` (grey text on paper), `--muted-ink` (grey text on black), `--line`, `--line-ink`.
- Red `--red`. On paper, text in red uses `--red-text` so it can be read.
- Six agents, each a pair: background and the text that reads on it (`--systems` / `--on-systems`…). Each case wears its agent's pair in chapter numbers, labels and hovers, through `accentVars(agent)`, which sets `--acc` and `--on-acc`:

## Rules

1. No decorative blur, no watercolour, no gradients.
2. No shadows, except the agent card (`--shadow-card`).
3. One data pattern: a label in grey Space Grotesk capitals + its value in Satoshi (`DataPair`).
4. Videos sit in boxes with their own proportions, never cropped, with a poster that has content (`VideoBlock`).
5. Always respect "reduce motion": durations become 0 on their own; anything that plays by itself stops.
6. Spacing on the 4 px scale (`--s-1` … `--s-8`), radii from the four tokens, durations and curves from the motion tokens.
7. Use a component from the manifest before writing a new one. A new component goes in `src/components/system/`, in the manifest and, by itself, in `/styleguide`.
8. A value that the tokens don't have is a question of taste: ask Ali, don't invent it.
