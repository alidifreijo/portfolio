# Fichas de los casos

Una ficha por proyecto del portfolio. Es la materia prima de cada caso: qué es, qué se sabe, dónde está el material y qué falta por contar.

**Cómo se usan**
- Las preguntas marcadas con `[ ]` son para Ali. Se responden en la ficha misma, con sus palabras, aunque sean notas sueltas.
- Cuando una ficha esté completa, se escribe el caso en la web (`src/content/projects/<caso>.yaml`) siguiendo la estructura de la ficha.
- La estructura de cada tipo de caso sale del brief, §7.3.
- Nada de la ficha se publica tal cual. La web va en inglés, pero la ficha puede ir como salga.

| Orden | Caso | Tipo | Estado de la ficha |
|---|---|---|---|
| 1 | [Cut Scenes](cut-scenes.md) | Web propia | Casi completa; el caso en la web ya existe |
| 2 | [cutouts](cutouts.md) | Web propia | Faltan la historia y el proceso; el caso en la web está vacío |
| 3 | [Silena](silena.md) | Web propia | Falta casi todo; no tiene caso en la web |
| 4 | [Monexa](monexa.md) | Propuesta a cliente | Material completo; falta contar el reto y el resultado |
| 5 | [Cupra](cupra.md) | Trabajo profesional | Hay que reescribirlo como caso de rol |
