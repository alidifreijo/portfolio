## Lo que ya sabemos
- **De dónde viene:** Ali hace collage analógico con tijera, pegamento y recortes de revistas. Quería un proyecto web alrededor de eso, inspirado en clipart.studio.
- **Modelo:** solo ella sube collages; cualquiera puede hacer collages con los recortes. Funciona con GitHub y Supabase.
- **Para qué:** aprender ese stack como base para futuras webs.
- **Por qué Vercel:** pasó por varios hostings hasta llegar a Vercel, siguiendo su checklist de «webs sólidas». Lo publica en un subdominio gratuito porque no quiere pagar dominio.
- **Contacto de privacidad:** el correo del estudio, compartido con Cut Scenes.
- **Lo siguiente que quiere hacer:**
